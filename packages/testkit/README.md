# jixu-testkit

Deterministic fixtures and Store contracts for Jixu adapter tests.

```bash
npm install --save-dev jixu-core jixu-testkit
```

The package provides fixed and sequence clocks, deterministic IDs and model
outcomes, a recording Signal sink, and the shared `defineStoreContract` suite
for Event Store implementations.
