# Security Policy

## Supported Versions

Jixu is currently pre-1.0. Security fixes are provided for the latest published version. Please reproduce an issue against the latest version before reporting it when possible.

## Reporting a Vulnerability

Please report suspected security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/joe960913/Jixu/security/advisories/new).

Do not disclose security vulnerabilities in public Issues, Discussions, or pull requests.

Please include, when available:

- The affected Jixu version.
- The expected and observed behavior.
- A minimal reproduction.
- The potential security impact.
- Any suggested mitigation.

Please avoid including real credentials, API keys, personal data, or other secrets in the report.
